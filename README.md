# 👶 프로젝트 명세서: 분할형 육아휴직 시뮬레이터 (Maternity Leave Planner)

본 프로젝트는 임신 중 육아휴직 분할 사용, 근무 구간 삽입, 출산휴가 배정 등 복잡한 조건의 휴가 일정을 가로 바(Bar) 형태의 타임라인으로 시각화하고 일정을 정밀하게 계산하는 단일 페이지 웹 애플리케이션(SPA)입니다.

---

## 1. 프로젝트 개요
* **목적:** 아내의 출산 예정일과 컨디션에 따른 유연한 휴직/근무 스케줄링 지원
* **배포 환경:** GitHub Pages (Static 웹사이트)
* **기술 스택:** HTML5, CSS3 (Flexbox/Grid), Modern JavaScript (Vanilla ES6+)
* **디자인 컨셉:** 모던하고 따뜻한 색감, 반응형 웹 UI (모바일 및 PC 지원)

---

| :--- | :--- | :--- |
| **출산전후휴가** | * 단태아 기준 **총 90일** 필수 보장<br>* **출산 예정일 이후 반드시 45일 이상** 배정되어야 함 | * 사용자가 지정한 출산휴가 시작일이 '출산 사후 45일 보장' 조건을 만족하는지 역산 검증 |

## 3. 기능 요구사항 (Functional Requirements)

### 3.1 입력 및 컨트롤 영역 (Input Panel)
* **출산 예정일 설정:** 달력 컨트롤 (`input[type="date"]`)을 통해 기준점 설정.
* **육아휴직 한도 선택:** `12개월` 또는 `18개월(남편 육휴 참여형)` 토글/라디오 버튼.
* **동적 블록(Interval) 제어:**
  * `[+ 임신중 휴직 추가]` 및 `[+ 중간 근무 추가]` 버튼 제공.
  * 추가된 블록은 생성 순서대로 전단부(출산휴가 전)에 체이닝(Chaining)됨.
  * 각 블록은 '기간(개월 또는 일수)'을 입력받아 다음 블록의 시작일을 자동 계산.

### 3.2 타임라인 시각화 엔진 (Visualizer Engine)
* 전체 휴가 프로세스의 총 일수를 계산하여 100% 기준으로 환산 후 Flexbox 비율로 가로 바 출력.
* **컬러 시스템 (Color Palette):**
  * `근무 (Work)`: `#e0e0e0` (연한 회색)
  * `임신 중 휴직 (Pregnancy Leave)`: `#ffb6c1` (라이트 핑크)
  * `출산전후휴가 (Maternity Leave)`: `#ff69b4` (핫 핑크)
  * `잔여 육아휴직 (Postnatal Leave)`: `#e6e6fa` (연보라)
* 각 블록 내부에 **구간 명칭 및 일수**를 텍스트로 표기 (예: `임신중 휴직 (61일)`).

### 3.3 상세 스케줄 리스트 (Result Output)
* 계산된 데이터를 기반으로 아래 양식의 테이블을 실시간 갱신 렌더링.
* **출력 항목:** 구분, 시작일, 종료일, 소요 일수.
* **인사팀 제출용 텍스트 가이드:** 사용자가 회사에 휴직 신청서 등을 제출할 때 참고할 수 있도록 구간별 신청 일자를 텍스트 템플릿으로 하단에 자동 생성.

## 4. 아키텍처 및 데이터 구조 설계

### 4.1 상태 관리 (State Management)
애플리케이션은 단일 상태 트리(Single State Tree) 구조의 캘린더 세그먼트 배열을 기반으로 연산을 수행합니다.

```json
{
  "dueDate": "2026-12-16",
  "totalParentalLeaveMonths": 18,
  "segments": [
    { "id": 1, "type": "PREG_LEAVE", "value": 1, "unit": "MONTH" },
    { "id": 2, "type": "WORK", "value": 3, "unit": "MONTH" },
    { "id": 3, "type": "PREG_LEAVE", "value": 2, "unit": "MONTH" }
  ]
}
```

### 4.2 연산 파이프라인 (Calculation Pipeline)
- 출산휴가 앵커링: `dueDate` 기준으로 출산전후휴가 90일 구간 고정 (출산 전 45일 시점 자동 추적).

- 전단부 체이닝: 사용자가 정의한 `segments` 배열을 순회하며 시작일과 종료일을 릴레이 방식으로 계산하여 출산휴가 전날까지 채움.

- 밸리데이션 체크: 전단부의 육아휴직 사용량 합계가 `totalParentalLeaveMonths`를 초과하는지 검증 후 경고 메시지 출력.

- 잔여량 엔드포인트 바인딩: `총 한도` - `출산 전 육휴 사용량`을 연산하여 출산휴가 종료일 바로 다음 날부터 잔여 육아휴직 블록을 생성하고 최종 복직 예정일을 도출.
